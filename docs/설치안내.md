# kcsc-design-mcp 설치 안내

건설기준(KDS·KCS 등) 원문을 Claude 대화창에서 바로 꺼내 쓰는 도구입니다.
**받는 분 PC 에 한 번만 설정하면 됩니다.**

---

## 0. 먼저 — 인증키를 받으세요

<https://kcsc.re.kr> 국가건설기준센터에 **회원가입하고 OpenAPI 키를 신청**합니다.

> **키는 각자 자기 것을 씁니다.** 남의 키를 받아 쓰지 마세요. 가입만 하면 누구나 받습니다.

---

## 1. uv 설치 (한 번만)

PowerShell 에서:

```powershell
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
```

이미 있으면 건너뜁니다 (`uv --version` 으로 확인).

---

## 2. Claude 설정에 넣기

`%APPDATA%\Claude\claude_desktop_config.json` 를 메모장으로 엽니다.
(주소창에 `%APPDATA%\Claude` 를 붙여 넣으면 폴더가 열립니다. 파일이 없으면 새로 만듭니다)

맨 바깥 `{` 바로 다음에 아래를 넣습니다:

```json
"mcpServers": {
  "kcsc": {
    "command": "uvx",
    "args": ["kcsc-design-mcp"],
    "env": { "KCSC_API_KEY": "받은_키" }
  }
},
```

- `mcpServers` 가 이미 있으면 그 안에 `"kcsc": { ... }` 만 추가합니다.
- 항목 사이 **쉼표**를 빠뜨리지 마세요. 대부분의 실패가 이것입니다.

파일 예시:

```json
{
  "mcpServers": {
    "kcsc": {
      "command": "uvx",
      "args": ["kcsc-design-mcp"],
      "env": { "KCSC_API_KEY": "받은_키" }
    }
  }
}
```

패키지는 `uvx` 가 알아서 내려받습니다. 따로 설치할 것이 없습니다.

## 4. 확인

새 대화에서:

```
KDS 14 31 10의 압축부재 폭두께비 표 보여줘
```

표가 표 모양 그대로 나오면 된 겁니다.

- 첫 호출은 30초쯤 걸립니다 (필요한 것을 내려받습니다). 두 번째부터는 바로 뜹니다.
- 수식 자리가 `〔그림〕` 으로 나오는 건 **정상**입니다. 원문이 이미지라 그렇고,
  이 도구는 없는 식을 지어내지 않습니다.

## uv 를 못 쓰는 경우

파이썬(3.10 이상)만 있으면 됩니다.

```powershell
pip install kcsc-design-mcp
```

설정에서 `command` 만 바꿉니다:

```json
"command": "kcsc-design-mcp",
"args": [],
```

## 안 될 때

| 증상 | 확인할 것 |
| --- | --- |
| 도구가 아예 안 보인다 | JSON 문법 오류일 가능성이 큽니다. 쉼표·중괄호·`\\` 확인 |
| "인증키가 거부되었습니다" | `KCSC_API_KEY` 값 확인. 앞뒤 공백이 섞이지 않았는지 |
| "TLS 인증서를 검증하지 못했습니다" | 회사 보안 프로그램이 중간에 낀 경우입니다. 안내대로 `KCSC_INSECURE=1` 을 `env` 에 추가 |
| `uvx` 를 찾을 수 없다 | 1번을 안 했거나, uv 설치 후 앱을 다시 켜지 않은 경우 |

## 결정트리 묶음 받아 쓰기

패키지에는 트리가 **예제 1개**뿐입니다. 저장소의 [`flows/`](https://github.com/lhs1152-lgtm/kcsc-design-mcp/tree/main/flows) 폴더에
결정트리 35개가 있습니다(LRFD 18 · 한계상태 9 · 허용응력 8). 내려받아 두 가지 중 하나:

- **내 PC 에 둔다(간단)** — `C:\Users\<이름>\.kcsc-mcp\flows\` 에 yaml 파일을 넣습니다.
- **여러 사람이 한 폴더를 함께 본다** — 공유 폴더(예: `\\서버\공유\kcsc-flows`)에 두고
  설정의 `env` 에 `"KCSC_FLOWS_DIR": "\\\\서버\\공유\\kcsc-flows"` 로 가리킵니다.
  **한 곳만 고치면 전원이 같이 바뀝니다.**

★**받은 트리를 그대로 쓰지 마세요.** 트리에는 KDS 가 값을 정하지 않은 항목에 대해
**만든 조직이 정한 값**(처짐 한계 · 진동수 회피대역 · 이음효율 등)이 들어 있습니다.
어느 값이 그런 것인지는 [`flows/README.md`](https://github.com/lhs1152-lgtm/kcsc-design-mcp/blob/main/flows/README.md) 의 표에
정리돼 있습니다. **자기 조직 기준으로 바꿔서 쓰십시오.**

## 자기 설계 흐름을 넣으려면

`C:\Users\<이름>\.kcsc-mcp\flows\` (또는 `KCSC_FLOWS_DIR`) 에 YAML 을 넣습니다.
Claude 에게 "새 결정트리 뼈대 만들어줘" 하면 `design_template` 이 형식을 내줍니다.
채운 뒤 "이 트리 검사해줘" 하면 `design_validate` 가 **적은 조항이 실재하는지 확인**합니다.
설계자가 확정(`검증: 설계자확정`)한 뒤 "확정 기록 박아줘" 하면 `design_stamp` 가 **그날의 기준 판**을 트리에 적어 두고,
이후 기준이 개정되면 검사가 "구판으로 확정된 트리"라고 알립니다.
